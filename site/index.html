devwrapped

Your year in code, wrapped: devwrapped turns your git history, shell history, and AI agent logs into a set of shareable slides, without anything leaving your machine.

It reads git, bash, zsh, fish, PowerShell, Claude Code, and Codex CLI. It keeps only counts and has no network code. Runs on Windows and Linux. macOS is best-effort.

cargo install devwrapped

Or download a binary from the releases page.

The story on this page uses built-in sample data. Tap it or use the arrow keys.
